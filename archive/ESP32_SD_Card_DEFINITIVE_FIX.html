ESP32 + Micro SD Card
DEFINITIVE FIX

An interactive, step-by-step resolution walkthrough.

What Was Actually Wrong?

Your cheap blue SD module has a buffer IC (74LVC125) that is always active. At power-on, it pulls GPIO 12 on the ESP32 HIGH through electrical leakage or crosstalk.

The Domino Effect:

GPIO 12 HIGH tells the ESP32 to run its internal flash at 1.8V instead of 3.3V.
The flash chip crashes at 1.8V → flash read err, 1000 → infinite boot loop.

The Fix: We will tell the ESP32 to permanently ignore GPIO 12 and always use 3.3V for flash.

Phase 1: Burn the eFuse (One-Time Fix)

Note: This is permanent and irreversible, but it is 100% safe for your ESP32-WROOM-32 board. You are simply locking what should already be the default. GPIO 12 remains fully usable for regular I/O afterwards.
1

Disconnect EVERYTHING

Unplug the SD module completely from the ESP32. Only the USB cable should be connected to your Mac.

2

Install esptool

Open Terminal (Cmd + Space, type "Terminal") and run:

pip3 install esptool
3

Find your ESP32's port

ls /dev/cu.*

Look for something like /dev/cu.SLAB_USBtoUART or /dev/cu.usbserial-0001. Copy it.

4

Burn the eFuse

Replace the port below with your actual port from step 3:

python3 -m esptool --port /dev/cu.SLAB_USBtoUART set_flash_voltage 3.3V

It will ask you to confirm. Type BURN and press Enter.

5

Power Cycle

Unplug and re-plug the USB cable. You're done. The `flash read err` is defeated forever.

100µF Capacitor

Absorbs the SD card's power-on current spike (100-250mA) so it doesn't brownout the ESP32. Solder across VCC and GND at the SD module pins.

┌─────────────┐ │ ─ ─ ─ ─ ─ │ ← stripe with minus signs │ 100µF 25V │ is the NEGATIVE side │ │ └──┬───────┬──┘ │ │ SHORT LONG leg leg │ │ GND VCC (5V)

10kΩ Pull-up Resistor

Keeps MISO HIGH when idle, preventing garbage reads. Connect one leg to ESP32 3.3V pin, and the other leg to GPIO 19 (MISO).

3V3 pin ─────────┐ on ESP32 │ ┌─────┴─────┐ │B B O G│ ← Brown-Black-Orange-Gold └─────┬─────┘ │ GPIO 19 ─────────┤─────────► blue wire to MISO on ESP32

Phase 4: Format the SD Card

On your MacBook, insert the 8GB card, open Terminal and run:

# Find your SD card (Look for your 8GB card — e.g. /dev/disk4)
diskutil list

# Format it (replace disk4 with YOUR disk number - BE CAREFUL!)
sudo diskutil eraseDisk FAT32 SDCARD MBRFormat /dev/disk4

Alternatively, use Disk Utility GUI: Select the card > Click "Erase" > Format: MS-DOS (FAT) > Scheme: Master Boot Record.

Phase 5: The Test Sketch

Create a new sketch in Arduino IDE, paste this complete isolation test, and click Upload.

/*
 * ESP32 + Micro SD Card Module — Isolation Test
 *
 * Board: "ESP32 Dev Module"
 *
 * Wiring:
 *   SD CS   → GPIO 5
 *   SD SCK  → GPIO 18
 *   SD MOSI → GPIO 23
 *   SD MISO → GPIO 19
 *   SD VCC  → ESP32 5V/VIN pin
 *   SD GND  → ESP32 GND
 *   10kΩ resistor between GPIO 19 and 3V3
 *   100µF capacitor across SD VCC and GND
 */

#include "FS.h"
#include "SD.h"
#include "SPI.h"

#define SD_CS_PIN 5

void setup() {
  Serial.begin(115200);
  delay(1000);

  Serial.println();
  Serial.println("====================================");
  Serial.println("  ESP32 SD Card Isolation Test");
  Serial.println("====================================");
  Serial.println();

  // Initialize SPI with explicit pins
  SPI.begin(18, 19, 23, SD_CS_PIN);  // SCK, MISO, MOSI, CS

  // Mount SD card at 1 MHz (slow and reliable)
  if (!SD.begin(SD_CS_PIN, SPI, 1000000)) {
    Serial.println("ERROR: Card Mount Failed!");
    Serial.println();
    Serial.println("Check:");
    Serial.println("  1. Is the SD card inserted fully into the module?");
    Serial.println("  2. Is the card formatted as FAT32 (MS-DOS FAT)?");
    Serial.println("  3. Is SD module VCC connected to 5V (NOT 3.3V)?");
    Serial.println("  4. Are all wires secure?");
    Serial.println("  5. Try a different SD card");
    return;
  }

  Serial.println("SUCCESS: SD Card Mounted!");
  Serial.println();

  // Print card info
  uint8_t cardType = SD.cardType();
  Serial.print("Card Type: ");
  switch (cardType) {
    case CARD_NONE:    Serial.println("No card"); return;
    case CARD_MMC:     Serial.println("MMC");     break;
    case CARD_SD:      Serial.println("SD");      break;
    case CARD_SDHC:    Serial.println("SDHC");    break;
    default:           Serial.println("Unknown"); break;
  }

  uint64_t cardSize = SD.cardSize() / (1024 * 1024);
  Serial.print("Card Size: ");
  Serial.print((uint32_t)cardSize);
  Serial.println(" MB");

  Serial.print("Total Space: ");
  Serial.print((uint32_t)(SD.totalBytes() / (1024 * 1024)));
  Serial.println(" MB");

  Serial.print("Used Space: ");
  Serial.print((uint32_t)(SD.usedBytes() / (1024 * 1024)));
  Serial.println(" MB");
  Serial.println();

  // Test write
  File file = SD.open("/test.txt", FILE_WRITE);
  if (file) {
    file.println("Hello from ESP32! SD card is working.");
    file.close();
    Serial.println("WRITE TEST: PASSED - /test.txt created");
  } else {
    Serial.println("WRITE TEST: FAILED - could not create file");
  }

  // Test read
  file = SD.open("/test.txt");
  if (file) {
    Serial.print("READ TEST: PASSED - Content: ");
    while (file.available()) {
      Serial.write(file.read());
    }
    file.close();
  } else {
    Serial.println("READ TEST: FAILED - could not open file");
  }

  // List root directory
  Serial.println();
  Serial.println("--- Files on SD Card ---");
  File root = SD.open("/");
  File entry;
  while (entry = root.openNextFile()) {
    Serial.print("  ");
    Serial.print(entry.name());
    if (entry.isDirectory()) {
      Serial.println("  [FOLDER]");
    } else {
      Serial.print("  (");
      Serial.print(entry.size());
      Serial.println(" bytes)");
    }
    entry.close();
  }
  root.close();

  Serial.println();
  Serial.println("====================================");
  Serial.println("  ALL TESTS COMPLETE!");
  Serial.println("====================================");
}

void loop() {
  // Nothing — one-shot test
}

Check the Output:

Open Serial Monitor, set baud rate to 115200, and press the EN (reset) button on the ESP32. You should see SUCCESS: SD Card Mounted! and file operations passing.
